# Medical Inventory Tracker

A responsive web application for tracking medical inventory with features for managing stock levels, expiration dates, and generating reports.

## Features

- 📊 Real-time inventory tracking
- 📅 Expiration date monitoring
- 🔍 Search and filter functionality
- 📤 Export to CSV
- 🌓 Light/Dark mode
- 📱 Mobile-responsive design

## Technologies Used

- HTML5, CSS3, JavaScript (ES6+)
- LocalStorage for data persistence
- CSS Variables for theming
- Responsive design with media queries

## Getting Started

1. Clone the repository
2. Open [index.html](cci:7://file:///c:/Users/GeeZ/Desktop/Projects/medical-inventory-tracker/index.html:0:0-0:0) in a modern web browser
3. Start managing your medical inventory!
